# AcIMSWeb

AcIMSWeb は、ブラウザ内に保存したアカウント情報を暗号化して管理する Ionic + React アプリです。データはこのブラウザの IndexedDB に保存され、サーバーへ送信しません。

## 主な機能

- マスターパスワードによる暗号化とロック解除
- アカウント情報の登録・編集・削除・検索
- JSON 形式でのインポート／エクスポート
- 一定時間の無操作後にロックする自動ロック
- スマホ限定の端末認証（WebAuthn）

## 利用方法

1. ホーム画面で **パスワード管理を開く** を選びます。
2. 初回はマスターパスワードを設定します。
3. パスワード管理画面の右下の追加ボタンから情報を登録します。
4. スマホでは、設定画面の **生体認証を設定する** から端末認証を登録できます。

端末への追加方法と、バックアップ時の注意は [利用ガイド](docs/USAGE.md) を参照してください。

## 開発

必要環境は Node.js 22 以降です。

```bash
npm ci
npm run dev
```

品質確認コマンド:

```bash
npm run lint
npm run test.unit
npm run build
```

`npm run build` は TypeScript チェックと本番ビルドを実行します。

## 注意事項

- マスターパスワードを忘れた場合、暗号化済みデータは復元できません。
- エクスポートファイルは平文です。安全な場所に保管し、不要になったら削除してください。
- 現在の WebAuthn は端末認証の確認に使います。アプリを完全に再起動した後は、復号キーを復元するためマスターパスワードが必要です。
