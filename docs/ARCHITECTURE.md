# アーキテクチャとデータ保護

## 構成

```text
src/
├── components/             再利用する画面部品
├── hooks/
│   └── useAppController    画面遷移、認証、自動ロックの状態管理
├── pages/
│   └── password-manager/  パスワード管理画面とその状態管理
└── services/
    ├── appStorage          Local Storage の永続設定
    ├── biometricAuth       WebAuthn による端末認証
    ├── passwordDb          IndexedDB への暗号化データ保存
    └── security            鍵導出、暗号化、復号
```

## データの流れ

1. マスターパスワードから PBKDF2-SHA-256 で AES-GCM 鍵を導出します。
2. 各パスワードエントリーを AES-GCM で暗号化します。
3. 暗号文、初期化ベクトル、作成日時などを IndexedDB に保存します。
4. 認証時に同じ鍵を導出し、エントリーを復号します。

マスターパスワード自体は保存せず、ソルトと検証用ハッシュだけを Local Storage に保存します。旧形式の平文記録が見つかった場合は、正常なマスターパスワード認証後に新形式へ移行します。

## WebAuthn の役割

スマホでは、端末内の Face ID・指紋認証などを WebAuthn のプラットフォーム認証器として利用します。PC では表示・登録・認証を行いません。

WebAuthn はこのアプリ起動中の再認証を確認するためのものです。復号鍵はメモリにのみ保持されるため、完全な再起動後にはマスターパスワードによる鍵導出が必要です。

## セキュリティ上の注意

- 本アプリはクライアントのみで動作します。端末を共有する場合は、ブラウザプロファイルも共有しないでください。
- サイトのコンテンツを信頼できる HTTPS 配信元からのみ取得してください。
- JSON エクスポートは暗号化されません。
- ブラウザデータを消去すると、登録情報も消えます。必要に応じてエクスポートしてください。
