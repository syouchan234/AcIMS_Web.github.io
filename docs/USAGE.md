# 利用ガイド

## 初回設定

1. ホーム画面の **パスワード管理を開く** を選びます。
2. 4 文字以上のマスターパスワードを設定します。
3. 管理画面右下の追加ボタンから、カテゴリとアプリサイト名を入力して保存します。

マスターパスワードはデータを復号するために必要です。忘れるとデータを開けないため、アプリ内の情報とは別の安全な方法で管理してください。

## スマホでアプリとして使う

ホーム画面の **アプリとして使う** で端末を選ぶと、各端末の手順を確認できます。

- iPhone: Safari の共有メニューから **ホーム画面に追加** を選びます。
- Android: Chrome のメニューから **ホーム画面に追加** または **アプリをインストール** を選びます。
- Windows: `Ctrl + D` でお気に入りに追加できます。Chrome／Edge のメニューからショートカットまたはサイトアプリを作成することもできます。

## 生体認証

生体認証はスマホ版だけで使えます。

1. マスターパスワードで管理画面を開きます。
2. 右上の設定を開きます。
3. **生体認証を設定する** を選び、端末の案内に従います。

生体認証は現在のアプリ起動中または自動ロック後の再認証に使えます。アプリを完全に終了・再起動した場合は、マスターパスワードでの認証が必要です。

## バックアップと復元

設定画面からデータを JSON 形式でエクスポートできます。エクスポートファイルにはパスワードを含むため、暗号化されたストレージなど安全な場所に保管してください。

インポートは現在の登録内容をすべて置き換えます。インポート前にエクスポートしてバックアップを作成することを推奨します。

## 初期化

認証画面の **初期化** は、登録したパスワードとマスターパスワードを削除します。この操作は元に戻せません。
